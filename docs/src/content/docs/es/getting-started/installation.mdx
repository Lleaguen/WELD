## Instalar

WELD requiere `zod` como peer dependency para la validación en runtime.

<Tabs>
  <TabItem label="npm">
```bash
npm install @weldjs/http zod
```
  </TabItem>
  <TabItem label="pnpm">
```bash
pnpm add @weldjs/http zod
```
  </TabItem>
  <TabItem label="yarn">
```bash
yarn add @weldjs/http zod
```
  </TabItem>
  <TabItem label="bun">
```bash
bun add @weldjs/http zod
```
  </TabItem>
</Tabs>

## React — Componentes UI + hooks

Instalá `@weldjs/react` para la librería completa de componentes (`Weld.Shell`, `Weld.Button`, `Weld.Table`, etc.) y el hook `useWeld`.

```bash
npm install @weldjs/react zod
```

```ts
import { Weld, WeldProvider, useWeld } from '@weldjs/react'
```

Requiere `react >= 18` como peer dependency.

## Adaptadores de Framework (solo HTTP)

Si solo necesitás el cliente HTTP sin los componentes UI, usá los subpath adapters:

<Tabs>
  <TabItem label="React (solo hook)">
```ts
import { useWeld } from '@weldjs/http/react'
```
Requiere `react >= 18` como peer dependency.
  </TabItem>
  <TabItem label="Vue">
```ts
import { useWeld } from '@weldjs/http/vue'
```
Requiere `vue >= 3.3` como peer dependency.
  </TabItem>
  <TabItem label="SolidJS">
```ts
import { useWeld } from '@weldjs/http/solid'
```
Requiere `solid-js >= 1.8` como peer dependency.
  </TabItem>
  <TabItem label="Angular">
```ts
import { toObservable } from '@weldjs/http/angular'
```
Requiere `rxjs >= 7` como peer dependency.
  </TabItem>
</Tabs>

## Requisitos

| Runtime | Versión mínima |
|---------|----------------|
| Node.js | 18+ |
| Bun     | 1.0+ |
| Deno    | 1.30+ |
| Browser | Cualquier browser moderno con `fetch` e `IndexedDB` |

## TypeScript

WELD incluye sus propios tipos — no necesitás ningún paquete `@types/`.

Configuración recomendada de `tsconfig.json`:

```json
{
  "compilerOptions": {
    "strict": true,
    "moduleResolution": "bundler"
  }
}
```

## Scaffold rápido

La forma más rápida de empezar es con la herramienta de scaffold:

```bash
npm create weld-app@latest mi-app
cd mi-app
npm run dev
```

Esto configura un proyecto completo con `@weldjs/react`, Vite y TypeScript.
